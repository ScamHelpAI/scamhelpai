# Mikado (headings)

Heading text on the website and browser extension uses **Mikado Bold** (`font-family: "Mikado"`; `font-weight: 700`).

The checked-in `mikado-bold.woff2` is the HvD **MikadoBoldDEMO** webfont for development. Before production, replace it with a properly licensed Mikado Bold webfont (WOFF2) from [HvD Fonts](https://www.hvdfonts.com/fonts/mikado) or your font vendor, then copy to:

- `brand/fonts/mikado-bold.woff2`
- `website/public/fonts/mikado-bold.woff2`
- `browser-extension/public/fonts/mikado-bold.woff2`
