ScamHelp extension — local test pages

Local QA only. These pages use harmless copy and example.com / example.org URLs. Do not enter real passwords or payment details. Serve this folder over HTTP (for example npx serve testing-pages) so the extension can scan pages; file:// may not work depending on browser policy.

For each page: open in a test profile, run Scan this page, record risk level, score, and “Why we think so”. Track false positives and missed cases separately after code changes.
